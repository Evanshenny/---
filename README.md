# 陈扬波个人作品集（最终版）

KAIROS / 陈扬波 AI 创意设计师个人作品集。包含桌面端完整视觉设计，以及按桌面画布等比例缩放的手机端显示方案。

## 本地预览

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

浏览器访问终端显示的本地地址。

## 构建检查

```powershell
pnpm test
```

## 使用 GitHub Desktop 发布源码

1. 在 GitHub Desktop 中选择“Add an Existing Repository from your Local Drive”。
2. 选择本文件夹。
3. 点击“Publish repository”。

项目已包含页面源码、案例图片、字体、工具图标和可下载的 PDF 简历；`node_modules`、构建产物、缓存和日志不会进入版本库。
